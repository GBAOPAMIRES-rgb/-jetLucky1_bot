🔑 Lucky Jet Browser Bridge

Безопасный read-only помощник. Теперь он может подготовить перехватчик публичных Lucky Jet WebSocket-событий для DevSnoop. Он отправляет на Render только события канала lucky-jet-* и безопасные поля раунда. SSID, cookies, токены и секретные поля не отправляются.

  1. Получите временный токен.
  2. Создайте скрипт ниже.
  3. В DevSnoop откройте Lucky Jet → Console → JavaScript REPL и выполните скрипт.
  4. После появления Bridge armed выполните действие в Lucky Jet, которое создаёт новое WebSocket-соединение/перезапускает игру. Не копируйте отдельные кадры.
