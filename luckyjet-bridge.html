🔑 Lucky Jet Browser Bridge

Безопасный read-only помощник. Он читает только видимый текст страницы. JavaScript делает только один read-only POST в Render с найденным видимым коэффициентом. Cookies, localStorage, SSID, токены Lucky Jet и сетевые данные не читаются. Cookies, localStorage, SSID, токены и сетевые запросы Lucky Jet он не читает.
